# Prompt avatar de l'auteur

Style de l'avatar : **flat illustration portrait, vector style, soft pastel palette, centered headshot, clean neutral background, friendly expression, shoulders up, 1:1 square ratio**.

Conventions :
- Taille : 512x512 px
- Format final : WebP (convertir avec `cwebp -q 85`)
- Chemin de destination : `static/images/authors/[id].webp`

L'avatar doit rester **coherent avec le profil de l'auteur** (age, ville, milieu) : un avatar de cadre en costume pour un jeune actif qui chronique ses brunchs du week-end decredibilise la signature.

**Ne pas donner un air de photographie.** Le style flat illustration est volontaire : un portrait photo-realiste genere est le genre de detail qui se retourne contre le site, et une illustration ne pretend rien.
